# Repository Summary: powerplatform-admin-scripts

## What this repository is
This repository is a growing collection of practical Power Platform administration and automation scripts.
The main goal is to make recurring operational tasks reliable, repeatable, and easy to run.

## Current focus
- Automated backup and export of Canvas Apps
- Interactive Power Apps environment and app discovery with guided export
- Backup and export of Power Automate Flows
- Cloud export of Power BI dashboard metadata
- Practical ALM support scripts for daily admin workflows

## Why this repository exists
Many Power Platform tasks are repeated manually and are error-prone.
This repository provides reusable PowerShell scripts to standardize these tasks and reduce risk.

## Example use cases
- Backup all Canvas Apps from a specific environment
- Browse environments visible to the current user and selectively export apps
- Store both msapp files and source-extracted app structure
- Export all Power Automate flows from an environment as JSON definitions
- Export Power BI dashboards (and tiles) from cloud workspaces
- Generate a run log for traceability and troubleshooting

## Who it is for
- Power Platform admins
- Makers with operational responsibility
- Consultants and DevOps engineers working with Power Platform

## Design principles
- Practical over theoretical
- Clear parameters and predictable outputs
- Safe defaults with optional advanced switches
- Scripts that are easy to copy, adapt, and run

## Status and roadmap
The repository is actively extended with additional scripts for governance, backup, ALM, and environment operations across Power Platform and Power BI.
Community feedback and contributions are welcome.
